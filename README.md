# Dynaconf - Maneja tus configuraciones en Python

[Dynaconf](https://www.dynaconf.com/) es un paquete que nos permite manejar más facilmente las configuraciones de nuestros programas escritos en Python. Dichas configuraciones pueden incluir: rutas a archivos, direcciones de red y puertos, usuarios y contraseñas, etc.

Este tutorial está basado en la versión 3.3.5. Abarca los aspectos más elementales del paquete.
